Edit dan hapus selalu meminta sandi owner. Menambah atau mencatat data baru—termasuk penjualan, produk, barang masuk, mutasi, dan dokumen—tidak meminta sandi. Owner dapat mengatur sandi untuk tindakan berikut:

Backup & Pemulihan

Simpan salinan produk, stok, pengaturan, dan riwayat penjualan ke file JSON. Simpan file backup di tempat aman.

Restore akan mengganti data aplikasi saat ini dengan isi backup.

Hapus Data Berdasarkan Jenis & Waktu

Pilih kategori data yang ingin dihapus dan rentang tanggalnya. Kosongkan tanggal untuk mencakup semua riwayat. Aksi ini meminta sandi owner.

Informasi Penyimpanan

Aplikasi berjalan offline. Data tersimpan di browser/perangkat yang digunakan melalui IndexedDB. Menghapus data browser atau mengganti perangkat dapat menghilangkan data jika belum di-backup.
